# Ejercicio 1: Verificación del entorno

Ejecuta en la terminal:

```bash
node --version
npm --version
npx tsc --version
```

- **Node.js:** entorno de ejecución que permite ejecutar JavaScript fuera del navegador.
- **npm:** administrador de paquetes que instala dependencias y ejecuta scripts del proyecto.
- **npx:** ejecuta herramientas de paquetes, como el compilador TypeScript, sin tener que instalarlo globalmente.

Completa aquí las versiones que devuelve tu equipo. Las versiones dependen de la instalación local.
