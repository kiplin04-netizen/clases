# Ejercicio 5: Auditoría de reglas de compilación

- `target`: versión de JavaScript que se generará.
- `module`: sistema de módulos utilizado en el código compilado.
- `strict`: activa comprobaciones estrictas de tipos para detectar errores.
- `rootDir`: directorio base de los archivos fuente.
- `outDir`: carpeta donde se guardan los archivos JavaScript compilados.

`tsconfig.json` centraliza las reglas del compilador. Así todos los archivos siguen la misma configuración, se detectan errores antes de ejecutar el programa y el proyecto mantiene una estructura consistente.
