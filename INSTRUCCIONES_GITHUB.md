# Antes de subir a GitHub

1. Descomprime `TypeScript_UNIVO.zip`.
2. Abre la carpeta `TypeScript_UNIVO` en Visual Studio Code.
3. Abre Terminal > Nueva terminal.
4. Ejecuta `npm install`.
5. Prueba un ejercicio, por ejemplo: `npx tsx Sesion01/ejercicio4_ficha.ts`.
6. Ejecuta `npm run check` para revisar los tipos.
7. Crea un repositorio en GitHub y sube el contenido de esta carpeta.

Para que la docente tenga acceso, agrega su cuenta como colaboradora del repositorio o configura la visibilidad y permisos según las indicaciones de la asignatura.

**Importante:** los comandos `node --version`, `npm --version` y `npx tsc --version` deben ejecutarse en tu computadora para registrar las versiones reales de tu entorno. No se inventan en este proyecto.
