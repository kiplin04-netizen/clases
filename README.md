# TypeScript UNIVO

Repositorio de ejercicios de TypeScript organizados por sesión.

## Requisitos
- Node.js (versión LTS recomendada)
- npm

## Preparar el proyecto
Abre una terminal dentro de esta carpeta y ejecuta:

```bash
npm install
```

## Ejecutar un ejercicio
Los ejercicios usan `readline` para recibir datos desde la terminal. Ejecuta el archivo deseado con:

```bash
npx tsx Sesion01/ejercicio1.ts
```

Cambia la ruta por el archivo que quieras ejecutar.

## Compilar y revisar
```bash
npm run build
npm run check
```

## Sobre la organización
Se incluyen 17 carpetas de sesión. Las sesiones 14, 17, 20 y 25 conservan únicamente su README, según las instrucciones de entrega. Las prácticas no forman parte de esta entrega. Los ejercicios incluidos se basan en los enunciados proporcionados.
